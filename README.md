# GearFlow

Sistema de Gerenciamento de Oficina Mecânica.

Projeto desenvolvido para a disciplina de Programação Orientada a Objetos II da UTFPR - Campus Cornélio Procópio.

## 👥 Desenvolvedores

- Gabriel Cotrim Miron
- Otávio Felício

## 🎯 Objetivo

Desenvolver um sistema para auxiliar no gerenciamento de uma oficina mecânica, permitindo controlar clientes, veículos, ordens de serviço, serviços, peças, orçamentos e pagamentos.

## 🛠️ Tecnologias

- Java
- MySQL
- JDBC
- Java Swing
- MVC
- Git
- GitHub

## 📋 Funcionalidades

- Gerenciamento de clientes
- Gerenciamento de veículos
- Gerenciamento de serviços
- Gerenciamento de peças
- Gerenciamento de ordens de serviço
- Gerenciamento de orçamentos
- Gerenciamento de pagamentos
- Consulta de histórico de manutenção
- Controle de estoque
